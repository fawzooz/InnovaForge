# Security

If you find a security problem in this repository, please tell us privately so we can fix it
before anyone else learns of it.

## How to report

Write to **info@fawzooz.ai** with "Security" in the subject. Tell us what you found, how to
reproduce it, and what it could expose. Please don't open a public issue or pull request for a
vulnerability, and please give us a reasonable time to fix it before you share the details.

We'll acknowledge your report within five working days and keep you posted as we work on it.

## Scope

This policy covers the contents of this repository, InnovaForge, only. For fawzooz.ai and its services,
write to the same address.
